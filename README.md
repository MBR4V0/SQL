# 🗄️ SQL

Consultas e modelagem de bancos de dados relacionais.

## 📂 Estrutura
- `01-ddl/` – CREATE, ALTER, DROP
- `02-dml/` – INSERT, UPDATE, DELETE
- `03-consultas/` – SELECT, JOINs, GROUP BY, subconsultas
- `04-projetos/` – [modelagem + scripts de um banco completo]

## 🛠️ SGBD utilizado
[MySQL / PostgreSQL / SQLite]

## ▶️ Como usar
Execute os scripts na ordem numérica no seu cliente SQL.
